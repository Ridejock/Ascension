# Controller prompt glyphs

Original art by the Game Art Director. Released CC0 1.0 Universal. Safe to reuse, including commercially, with no attribution required.

Each sheet is 128×48 pixels: 16×16 tiles, 18 per device, described by the JSON atlas beside the PNG (`tile_size` and `tiles`). The d-pad and stick tiles are the same picture on every sheet. Xbox, PlayStation, and Switch each keep their own copy so a sheet stands alone.

- `xbox.png` — a, b, x, y, lb, rb, lt, rt, menu, view, dpad_up, dpad_down, dpad_left, dpad_right, stick_l, stick_r, stick_l_click, stick_r_click
- `playstation.png` — cross, circle, square, triangle, l1, r1, l2, r2, options, create, and the same d-pad and stick tiles
- `switch.png` — a, b, x, y, l, r, zl, zr, plus, minus, and the same d-pad and stick tiles
