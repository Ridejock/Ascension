# Outer Barrow custom tiles - ORIGINAL ART (CC0, ours). Source maps for tools/make_barrow.py.
# Drawn from scratch; no paid-pack pixels. Palette: ../../palette.gpl (no teal, no skin).
#
# OBJECT MAPS  [name WxH]  (W,H in 16px tiles). Rows are padded with '.'; shapes are drawn bottom-aligned as written.
#   .        empty
#   a-z      stone pieces (gstone ramp). Each letter is its own stone: auto shaded from the top-left,
#            seams to a different letter on the stone's bottom/right side become gstone_d.
#   A-Z      same stone letters as a FRONT/SIDE face (ramp shifted one step darker).
#   x        crack / deep joint (gstone_d)      K  doorway darkness (outline colour)
#   *        moss (fol1)                        :  lichen (wstone1)
#   1-4      wood, painted directly with wood ramp steps 1..4 (hair1, leath1, leath2, dirt2)
#   ^        grass blade overlap (fol1m)
# A 1px outline (#1A1423) is added around every object; enclosed holes become gstone_d.
# Ground shadows: 'shadow <name-prefix> <colour>' adds a soft 1-2px shadow under the object's base.
shadow cairn_ gstone_d
shadow stone_ring_3x3 fol0
#
# RAMPS (dark -> light, last = top-left highlight)
ramp stone   gstone_d gstone0 gstone1 gstone2
ramp wood    hair1 leath1 leath2 dirt2
ramp grass   fol0 fol1 fol1m fol2
ramp walltop  gstone0 gstone1 gstone2 gstone2
ramp wallface gstone_d gstone0 gstone1 gstone1
#
# GROUND FILLS: base colour, then stamps "colour:count:pattern" (pattern rows split by '/', '.' = skip,
# digits index into the stamp's colour list). Positions are seeded and wrap, so fills tile seamlessly.
ground grass  seed=4  base=fol1m  stamp=fol1,fol2:22:1./01   stamp=fol1:10:0/0
ground heath  seed=11 base=fol1   stamp=gstone1,fol0:26:0/1   stamp=dirt0:14:0   stamp=fol0:16:0   stamp=wstone0:6:0   stamp=leath1:6:0/0
ground heath2 seed=23 base=fol1   stamp=gstone1,fol0:22:0/1   stamp=dirt0:18:0  stamp=fol0:14:0   stamp=wstone0:8:0   stamp=leath1:4:00
ground heath3 seed=37 base=fol1   stamp=gstone1,fol0:30:0/1   stamp=dirt0:10:0  stamp=fol0:20:0   stamp=wstone0:4:0   stamp=hair1:3:0
ground path   seed=5  base=dirt0  stamp=leath1:14:0   stamp=dirt1:8:0   stamp=dirt2,leath1:5:0/.1
ground moundgrass seed=41 base=fol1m stamp=fol2,fol1m:9:0/1   stamp=fol1:5:0
ground rocky  seed=9  base=gstone0 stamp=gstone2,gstone1,gstone_d:12:01/12.2/.22   stamp=gstone_d:10:0  stamp=fol0:6:0   stamp=gstone1:12:0
#
# TRANSITIONS: inner terrain fills the tile, outer terrain covers the corners in the mask
# (corner bitmask TL=1 TR=2 BL=4 BR=8; same 15 names as the Time Fantasy / OpenRTP path sets).
# Edge = seeded wrap-around value noise (period 16, so neighbours match) plus 1px blade spikes from the
# outer terrain; the outer terrain casts a 0-2px shadow below/right, colours picked from the list.
transition heath_in_grass  inner=heath  outer=grass seed=3  shadow=fol0,fol1
transition path_in_heath   inner=path   outer=heath seed=8  shadow=leath1,hair1,leath1
transition rocky_in_grass  inner=rocky  outer=grass seed=13 shadow=gstone_d,fol0
transition rocky_in_heath  inner=rocky  outer=heath seed=21 shadow=gstone_d,fol0
#
# MOUND: 3x3 autotile cut from one 48x48 mound; front (south) face height, corner radius, crown/flank band
# widths, cluster density, ground shadow colour under the base.
mound face=5 radius=7 top=moundgrass crown=5 flank=6 density=0.22 shadow=fol0
#
# DRY-STONE WALL: footprint arms by connection (N E S W). The top face uses [wall_top] (small hand-placed
# cap stones, lit ramp 'walltop'); the front face below every south edge uses [wall_face] (larger
# irregular stones, ramp 'wallface'). Both maps wrap at 16px, so runs never show tile seams or stripes.
wall top_y=3 depth=7 face=5 arm=8
